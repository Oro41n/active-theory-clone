如果上面显示「可以运行」

  1. 确保已运行过 python tools/build.py（下载约 180 MB 真实资产）
  2. 运行 python tools/serve.py，打开 http://127.0.0.1:8080
  3. Windows 用户也可直接双击 start.bat（macOS/Linux 用 ./start.sh）

说明：原版引擎需要 WebGL2 或 GPU 实例化扩展，且其 Antimatter 粒子系统依赖浮点纹理 (OES_texture_float / EXT_color_buffer_float)。软件渲染器（SwiftShader / llvmpipe） 能显示加载过场，但无法进入 3D 场景——这是原站自身的限制，非镜像缺陷。
